Publish the teammate after testing it in the [Builder](/agents/building). Select **Manage my team** in the sidebar, then open **Deploy** on the teammate's card in **My Team**.

## Choose an entry point

| Entry point | How people use it | What to configure |
| --- | --- | --- |
| **Shareable Link** | Open the teammate's chat page as a guest | Generate and share a public link |
| **Embed Widget** | Chat with the teammate from your website | Enable the widget and set the allowed domains |
| **REST API** | Use the teammate through your own application or backend | Use an agent runtime key from your server |

Publication and access are separate settings. Workspace visibility follows ownership and access rules on your deployment. Choose and configure an external entry point to let end users reach the teammate.

## Share a link

1. In **Deploy**, select **Shareable Link**.
2. Select **Generate Link** and copy the public URL.
3. Open it in a private browser window and send a question as a visitor.

Anyone with the link can start a guest conversation. Review the teammate's instructions, knowledge, tools, suggested prompts, and file handling before distributing the URL. Use **Reset Link** to replace the URL or **Disable Link** to close guest access through it.

## Embed a widget or connect an application

- For a website, see [Embed a teammate as a widget](/agents/widget-embed) for the script, domain settings, and key rotation.
- For an application, see [SDK and API keys](/guides/sdk) for creating and using a runtime key. Keep the runtime key on your server.

## Check the first conversation

Open [Conversation Logs](/deployment/conversation-logs), filter by the teammate and its entry point, and select the conversation you just started. Inspect the reply and recorded tool calls before rolling it out more widely.

For link management from code, see the [share-link endpoints](/api-reference/agents/get-agent-share-link).

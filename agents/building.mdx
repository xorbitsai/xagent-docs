Use the Builder to configure a teammate for a specific job. This walkthrough uses a **Product Support** teammate that answers setup, account, and billing questions.

## Before you start

- Configure at least one [language model](/models/llm) that supports the tools the teammate will use.
- To add documentation retrieval, configure an [embedding model](/models/embedding) and [upload documents to a knowledge base](/knowledge/uploading). Use sample product documentation if you plan to test guest access.

## Choose a starting point

Select **+** in the workspace sidebar, then **Add a teammate**. Select **Build** under **Build your own teammate**.

To customize a [preconfigured teammate](/templates/overview) you already added, select **Manage my team** in the sidebar and open **Edit** on its card in **My Team**. Review the prefilled configuration and connect any resources the job requires.

## Configure the teammate

1. Name it **Product Support** and give it a short description.
2. Write instructions that define its role. For example:

   > Answer setup, account, and billing questions using the attached product documentation. Give clear steps and ask a follow-up when the request is ambiguous.

3. Select a main model. Attach your product documentation knowledge base and enable the tools and skills needed for the job.
4. Add suggested prompts, such as “How do I reset my workspace password?” Use prompts that match the documentation you uploaded.

You can also configure optional **Fast Model**, **Vision Model**, and **Long Context Model** settings. The main model is the default for the teammate's work.

### Choose an execution mode

| Builder mode | Use it for |
| --- | --- |
| **Flash** | Simple requests that can run in a single model call |
| **Balanced** | Requests where the teammate may need to use tools and reason through the results |
| **Think** | Complex requests that benefit from an execution plan with multiple steps |

See [Task execution](/tasks/execution) for how these modes appear when a task runs.

## Test in Preview

Ask a question that the product documentation answers. Review the reply and any recorded tool calls. Test an out-of-scope question as well, then adjust the instructions or resources as needed.

## Save and publish

1. Select **Create** to save a new draft, or **Update** to save changes to an existing teammate.
2. Select **Publish** when it is ready. Use **Start chat** to test the published teammate from your workspace.
3. To give other people access, open **Deploy** on the teammate's card in **My Team** and [choose a distribution method](/agents/sharing).

You can unpublish a teammate from the Builder and publish it again later.

## Troubleshooting

- **Preview does not start.** Check the main model, credentials, and provider quota.
- **A tool is missing.** Check the selected tools and connector setup. Some capabilities require an additional model or authorization.
- **The teammate misses a document.** Confirm the knowledge base is attached and its documents have finished indexing. Try the query in [retrieval testing](/knowledge/retrieval).

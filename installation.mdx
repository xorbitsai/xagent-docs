## Local evaluation

Use Python 3.11 or later. The published package includes the web UI and uses SQLite by default.

<CodeGroup>

```bash uv
uv tool install xagent-ai
xagent
```

```bash pip
python -m venv .venv
source .venv/bin/activate
python -m pip install xagent-ai
xagent
```

```bash uvx
uvx --from xagent-ai xagent
```

</CodeGroup>

Open `http://127.0.0.1:8000`, create the first administrator at `/setup`, and configure a model. Xagent stores local data under `~/.xagent` by default. Use `XAGENT_STORAGE_ROOT` to choose another location.

## Self-host with Docker Compose

```bash
git clone https://github.com/xorbitsai/xagent.git
cd xagent
cp example.env .env
docker compose up -d
```

Open `http://localhost` for local setup. Before exposing the service to other users, review the [configuration guide](/deployment/configuration) and the [self-hosting guide](/deployment/self-hosted). Production browser access requires HTTPS and a browser that supports Web Locks.

## Develop from source

Use an editable install for backend development. From the root of the Xagent source repository, run these commands in a virtual environment.

```bash
python -m pip install -e .
python -m xagent.web.__main__
```

The frontend runs separately in development. Follow the [frontend development instructions](https://github.com/xorbitsai/xagent/blob/main/frontend/README.md) for Node dependencies and the API and WebSocket settings. Source builds need access to the npm registry and the SheetJS CDN.

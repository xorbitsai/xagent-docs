A template is the YAML definition behind a preconfigured teammate. Built-in definitions live in the Xagent source repository under [src/xagent/templates/built_in](https://github.com/xorbitsai/xagent/tree/main/src/xagent/templates/built_in).

## Define the teammate

Create a YAML file with a unique `id`, a `name`, a `category`, and an English entry in `descriptions`. For a **Meet** and **Hire** card, add a `persona` with a display name and write the introduction and setup questions for its first conversation.

```yaml
id: product-release-writer
name: Product Release Writer
category: Support
descriptions:
  en: Drafts customer updates from product release notes.
tags:
  en:
    - release notes
    - customer updates
persona:
  name: Avery
  role:
    en: Product Release Writer
  intro:
    en: I turn release notes into customer updates.
  kickoff_questions:
    en:
      - Who will read the update?
sample_prompts:
  en:
    - title: Draft a customer update
      prompt: Turn these release notes into a short customer update.
agent_config:
  instructions: Use the supplied release notes to draft a short customer update.
  execution_mode: balanced
  skills: []
  tool_categories: []
```

Use locale-keyed values for translated descriptions, tags, and sample prompts. When you provide `persona.intro` or `persona.kickoff_questions`, include an English entry. For an avatar, use an app-relative path to a bundled image.

Use category IDs in `agent_config.tool_categories`. Common IDs are `basic_tools`, `web_tools`, `file`, `code_execution`, and `knowledge`. See the [built-in templates](https://github.com/xorbitsai/xagent/tree/main/src/xagent/templates/built_in) for working configurations.

The execution modes are `flash`, `balanced`, `think`, and `auto`. If you omit `execution_mode`, the template loader uses `balanced`. See [Task execution](/tasks/execution).

## Test and contribute it

1. Add your YAML file to `src/xagent/templates/built_in` in an Xagent source checkout and restart Xagent.
2. Open **Add a teammate** from the workspace, then select **See all teammates**.
3. Find your card and select **Meet [name]**, then **Hire [name]**. Verify that the introductory conversation opens and that the teammate handles the sample prompt.
4. Open a pull request in [the Xagent repository](https://github.com/xorbitsai/xagent). Include the use case and what you tested.

Use an [existing Workforce template](https://github.com/xorbitsai/xagent/blob/main/src/xagent/templates/built_in/marketing-growth-marketing-workforce.yaml) as a reference when contributing a multi-teammate configuration.

Browse preconfigured teammates by job. Review what each specialist does, which tools or connected apps it uses, and the questions you can try.

## Browse and add a teammate

1. Select **+** in the workspace sidebar, then **Add a teammate**. Pick a specialist from the dialog or select **See all teammates** to open the **Add teammates** page.
2. Choose a card and select **Meet [name]** to review the teammate's details.
3. Select **Hire [name]** to add it and open its introductory conversation. If you already added it, select **Chat** to use it again.
4. Answer any setup questions and connect the apps it needs before giving it work that depends on them.

## Customize a teammate you added

Select **Manage my team** in the sidebar. In **My Team**, open the **Teammates** tab and select **Edit** on the teammate's card. Review its model, instructions, tools, and knowledge. Use **Preview** to try changes and **Update** to save them.

To start from your own configuration, use **Build your own teammate** and follow [Build a teammate](/agents/building).

## Start from a Workforce template

The **Add teammates** page also lists Workforce templates. On a Workforce card, select **Use Template** to open the generated Workforce in the builder. Review the manager and workers before publishing it. See [Building Workforces](/workforces/building).
